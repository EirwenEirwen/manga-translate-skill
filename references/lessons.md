# 经验沉淀（持续更新）

每完成一本，把**可泛化**的经验一行一条追加到对应小节，格式：`- YYYY-MM-DD《作品》： 经验`。
书内专属设定（人物、术语）留在该工程的 `work/glossary.md`，不要搬进来。

## 排序与检视

- 2026-10-07《测试》：合成图太"干净"（无分格、文字稀疏）会让漫画检测器返回 0 区域；测试图要有分格线、加粗笔画、贴近真实版式才算数。

## 翻译与审校

- 2026-10-07《论文图示例》：check 报"术语未对齐"时不一定是译文错——"GLUE 基准"“延迟-精度权衡”这类惯用译法是对的，应反过来把术语表改成"基准测试/基准"多选形式；真正的错译（批大小写成批次规模）才走 overrides。

## 论文图（术语与不译清单）

- 2026-10-07《论文图示例》：工具对论文图能检出标题/图题/大标注，图例条目、轴标签、刻度基本漏检；OCR 必须换 paddleocr（48px 对英文幻觉日文）。agent 补充的区域只进对照表、不参与重渲染，这是"论文图默认交对照表"的根本原因。
- 2026-10-07《论文图示例》：相邻小字（柱状分类标签与图题）会被粘成一个 region，标注时把 source 拆成完整两句分别处理，或整块翻译后在 notes 记录拆分。
- 2026-10-07《论文图示例》：渲染后逐区域核对时发现，曲线图的细线可能被 inpaint（lama_large@1024）连带抹掉，柱状图的粗色块则安全——细线图表不要走重渲染，只交对照表。

## 工具与渲染

- 2026-10-07《测试》：detect_only 配置里 translator 用 `none` 会"空译文→regions 清空→JSON 0 区域"，必须用 `original`；渲染前必须把 `out/render/<名>.json` 覆盖回工具标准位置 `<图片目录>/manga_translator_work/json/<名>_translations.json`，否则渲染读到的是未写回的旧 JSON（表现为"擦了原文又画回原文"）。
- 2026-10-07《测试》：render.direction 只接受 auto/horizontal/vertical，不接受 h/v。
