# 翻译守则（JP→CN）

第 3 步标注、第 4 步批量翻译提示词、第 5 步审阅都以此为准；本文件会随每批翻译提示词整体下发。

## 总原则

- 译"话"不译"字"：台词要能脱口而出，书面腔只留给旁白和 sign。
- 一致性优先于单句最优：人物自称、称呼、口头禅、术语全册统一，以 `glossary.md` 为准。发现更好的译名 → 先改表，再批量改已译条目。
- 中文长度尽量不超过日文 1.4 倍（气泡排版空间有限）；语气靠标点和句式，不靠塞字。

## 人称与语气

- 自称映射依人物表执行，常见：私→我；俺→我（粗豪角色可保留"俺"）；わたし（撒娇场合）→人家；わし→老夫；吾輩→本大爷；うち→俺家/我（关西少女视语气）。
- さん→同学/先生/桑（全书统一一种）；ちゃん→小X/阿X；君→你/同学；様→大人/少爷；前辈/后辈直接沿用。
- 敬语降级表达：ですます 译成礼貌但别啰嗦；敌意称呼（貴様、てめぇ）的火气要在译文里可感。
- 日语常省主语：中文按场景补主语或保留省略，但**必须与 speaker 字段一致**——这是审阅第一查。

## 肯定否定（最高频翻错点）

- 双重否定=肯定：~ないわけではない → 并不是不……；~ないではいられない → 忍不住。
- ~わけにはいかない → 不能……；~しなければ → 不……不行（=必须）。
- 反问句保持反问力度，别译成陈述；か/の/かな 的语气差异要在中文句尾体现。
- 禁止句与许可句：~てはいけない/なくてもいい 别互相串。
- 拿不准整句肯否 → 回读前后气泡的因果链再定，仍定不了 → 进 questions.md。

## 因果与逻辑

- から/ので → 因为/由于；のに → 明明……却；ば/たら → 如果/一旦；つつ → 一边……一边。
- て形连接兼有因果与先后两种读法：选与剧情更通的一种，前后气泡要接得上。
- だけ/しか~ない → 只/仅；また/さらに → 又/再；うっかり混肴会颠倒剧情信息，审阅重点过。

## 气泡类型处理

- `dialogue`：口语，可带语气词；尾助词（よ、ね、ぞ）决定中文句尾（呢/啊/哦/咯）。
- `thought`：内心独白，去掉"呢""吧"等外向语气词；是否用括号包裹依作品惯例（全书统一）。
- `narration`：书面语、简洁、有文学感；回忆性旁白可加"那时……"之类时间标记。
- `onomatopoeia`：拟声尽量短促（ドン→轰/咚、ゴゴゴ→隆隆）；拟态词意译（シーン→鸦雀无声、ドヤ顔→得意脸）；**无法识别完整的才 keep_original**，能读全的必须译。
- `sign`/`bg_text`：按物件功能译（招牌/标语/字幕），能短则短；纯装饰性乱码花纹填 keep_original 并 notes 注明。

## 专有名词

- 首次出现即登记 `glossary.md` 专有名词表；已有官方/通行译名优先沿用，自创译名选常用读音并在表里记备选。
- 技能/组织/地名前后必须一致；同一词在 check 里报"同句异译"时以 glossary 定夺。

## 禁止

- 中日同形异义直搬：手紙→信（不是手纸）、勉強→学习（不是勉强）、丈夫→结实、娘→女儿、新聞→报纸（不是新闻）、走る→跑。
- 译文残留日文假名（刻意保留的拟声/专有名词除外，须在 notes 说明理由）。
- 把 OCR 缺失的部分脑补成通顺句子而不对照放大图核实。
- 审阅时发现错误只记录不修——必须当场改进 overrides.json。
